# Stock Trading Platform

A modern stock trading web application inspired by Zerodha Kite, designed to provide users with an intuitive trading dashboard to monitor stocks, manage watchlists, track portfolios, and manage orders.

## Tech Stack

- React.js
- TypeScript
- Vite
- Supabase
- SQL
- CSS

## Key Features

- User Authentication
- Interactive Trading Dashboard
- Stock Market Watchlist
- Portfolio and Holdings Management
- Order Management
- Stock Details and Market Overview
- Supabase Database Integration

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/kashif1618/Northstar_Trade.git
```

2. Navigate to the project directory:

```bash
cd Northstar_Trade
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

5. Start the development server:

```bash
npm run dev
```

## Backend & Database

Supabase is used for backend services, database management, and authentication.
